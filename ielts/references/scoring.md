# 评分依据与可评范围

官方来源核验日期：2026-09-07。只概括规则，不把民间经验表标成官方精确换算。后续核查评分变更时优先打开以下原始来源。

- [IELTS scoring in detail](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)：总分为四科平均，取最近的0.5，.25和.75向上。L/R按40题换算，各卷边界可能不同。
- [Writing Band Descriptors](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)：按任务达成/回应、连贯衔接、词汇、语法判断。Task 1用TA，Task 2用TR；两题合成写作成绩时Task 2权重为Task 1的两倍。
- [Speaking Band Descriptors](https://ielts.org/cdn/ielts-guides/ielts-speaking-band-descriptors.pdf)：流利与连贯、词汇、语法、发音四项等权。只有文字无法判断实际发音与停顿。
- [官方练习与材料](https://ielts.org/take-a-test/preparation-resources/sample-test-questions)：区分Academic与General Training的阅读和写作，听力和口语相同。

## 客观题

只有完整40题、同一次作答且核对答案的L/R成绩才可参考相应试卷换算表。记录表的出处；无对应表时报告原始分，或明确标记官方平均参考值的粗略估计，不自行补出精确半分区间。官网平均参考：听力16/23/30/35题对应约5/6/7/8；Academic阅读15/23/30/35题对应约5/6/7/8；GT阅读15/23/30/35题对应约4/5/6/7。这些不是每套卷的固定阈值。

单个Part、单篇阅读、词汇听写只报对题数、总题数和条件，不乘四换算Band。复练、看答案后练习不进入首次模考趋势。没拿到标准答案时，AI推导答案与官方答案分开标记。

## 主观题

- 先指出原文/音频证据，再判断符合哪个描述；证据不足的维度留空。可给学习用估分或区间，并标记AI估计、样本范围与未观察维度。
- 不机械减0.5，不以“模板”“词简单”“重复三次”等单项印象给整篇固定封顶分；需要结合官方描述与实际影响。
- AI给出的示范改写不是用户能力提升的证据。用户独立修订与陌生题复测才提供额外信息。
- 不默认跑多模型或购买教师服务。同题存在差异时检查评分依据；外评只在用户要校准或报名判断时作为选项。
- Academic Task 1需要看图/表，缺图不能评价数据准确性和任务达成。GT Task 1是书信，不套图表标准。

## 总分

四科分齐全才计算Overall；缺项填null，绝不补0或从其他日期拼成一次考试。计算示例：8、8、6.5、6.5 → 平均7.25 → 总分7.5；7.5、8、6.5、6.5 → 平均7.125 → 总分7.0。计算值保留所有分项的来源，混入AI/自估分的总分不是正式成绩。

分数录入接受0—9之间的整分和半分。原始答对数须为0—40整数。官方成绩单优先于近似换算，不用民间表改动正式分数；材料间冲突保留并待核。
