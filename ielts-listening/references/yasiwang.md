# 雅思王语料库与小程序结果

2026-09-07查到学为贵官方的[雅思王听力真题语料库介绍](https://www.guixue.com/p/book/listenCorpus/detail.html)：提供配套音频，介绍微信“雅思听力小程序”及拼写练习。页面也含旧版内容；当前入口、章节、收费/兑换方式须以用户实际使用版本为准。尚未核验到开放的个人进度API或导出契约。

## 接入顺序

1. 用户已有可用的官方导出/API：先核对字段、来源与授权范围，再只读导入。
2. 用户提供结果页/截图：用当前环境可用的图像读取能力，或按用户授权的OCR方式提取；只凭小图看不清的数值标待核。不得因导入截图而擅自上传到另一个OCR服务。
3. 用户口述：“第3章第2节，50词错8个”：记录来源为 `user_report`，可算42/50=84%；版本、倍速、遍数未知保留null。无需为了记一次结果要求填写长表。

没有真实接口时不抓取隐藏私有API、不逆向登录、不承诺自动同步。公众号文章有材料入口不代表暴露个人学习进度。

## 最小结果字段

| 字段 | 作用 |
|---|---|
| `material_version`、`chapter`、`unit` | 避免不同版的“第3章”混在一起 |
| `total_questions`、`correct_count` | 总词数与正确数；只有错误数没总数时不算正确率 |
| `speed`、`attempt_kind`、`attempt_number` | 区分倍速、首次、复听 |
| `wrong_words` | 有实际错词才逐词诊断；空列表不表示全对 |
| `source_type`、`source_ref`、`imported_at` | 来自结果页还是口述、导入时间；不是学习发生时间 |

使用共用记录规则保存到 `listening/corpus/`，`type: corpus-dictation`，`band_estimate: null`。`record_id`优先用平台实际作答ID；没有ID就用日期、材料、遍数和来源记录区分，重复导入同一结果先去重，不把复练与首次合并。

## 教学处理

先分清“词不认识、认识但没辨音、听出了却拼错、词尾/复数遗漏”。不从错误拼写武断反推原因；必要时用一个小抽测区分。

一轮只挑少量反复错词：听原音再写 → 对照词形 → 遮住再写 → 次日或下次混入新顺序重测。倍速由用户正在使用的训练方案和实际表现决定，不照搬旧页面的统一加速要求。

语料库听写和整套听力并列记录：前者练声音与拼写，后者还检验语境理解、定位、同义替换与干扰项。听写90%不能推导听力Band。推荐整题迁移练习时遵守当前时间预算。
